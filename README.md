# Занос

Убивалка времени для телефона: машина едет сама, держишь палец на левой или правой
половине экрана — уходит в занос в ту сторону, отпускаешь — выравнивается. Очки за угол
и длину заноса, вылет с трассы — конец заезда, рекорд хранится на телефоне.

Работает как PWA: открыть в Chrome → «Добавить на главный экран» → играет офлайн на весь экран.
